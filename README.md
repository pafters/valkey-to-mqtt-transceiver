# valkey-to-mqtt-transceiver

## Описание

Сервис передачи данных из Valkey хранилища в удаленный MQTT-клиент.

Реализованный функционал:
1. Подписка на обновление данных Valkey;
1. Обновление кэша названий устройств, организаций и локаций каждые N минут данными из таблиц "*devices*", "*sites*", "*locations*" соответственно базы данных "*m500*";
1. Функция передачи данных из Valkey по подписке (п.1) в MQTT.

### Особенности построения топиков для передачи значений в MQTT
* **Топик** - Строка, которая используется для идентификации и маршрутизации сообщений. 
* **Тип данных** - Строка.
* **<<Префикс топика>>** - Наименование, с которого будут начинаться все топики сервиса valkey-to-mqtt-transceiver. Указывается в env файле (переменная "*MQTT_TOPIC_PREFIX*").
* **<<Название организации>>** - Берется из поля "*name*" таблицы "*sites*" базы данных "*m500*". Например организация "DEMO".
* **<<Путь из локаций устройства>>** - Весь путь из названий от внешней до корневой локации устройства (Например для устройства "DEVICE INSIDE" путь из локаций может быть "DEMO/49/").
* **<<Название устройства>>** - Название устройства указывается из поля "*name*" таблицы "*devices*" базы данных "*m500*".
* **<<Алиас>>** - Параметр устройства, по которому передается значение из Valkey в MQTT-клиент.

**Структура топика:** ```<Префикс топика>/<Название организации>/<Путь из локаций устройства>/<Название устройства>/<Алиас>```

**Преобразование спецсимволов в топике**:
MQTT-брокер не поддерживает ряд спецсимволов, а именно: $, #, +. Для предотвращения ошибок было добавлено правело преобразования таких символов в соответсвии со следующим списком преобразований:
```
$ преобразуется в <<dollar>>
+ преобразуется <<plus>>
# преобразуется в <<sharp>>
```

**Пример:** Для параметра "Run" устройства "Электон-05 800А" организации "#ИРЗ ТЭК". Допустим префикс топика будет иметь значение "__TRANSMITTER", тогда весь передаваемый в MQTT-клиент топик из данного сервиса будет иметь вид:
```__TRANSMITTER/<<sharp>>ИРЗ ТЭК/Удмуртия/Выставочная станция/Электон-05 800А/Run```.

### Особенности построения значений для передачи в MQTT-брокер
MQTT-клиент принимает значение в строковом типе данных. Поэтому, передаваемое из Valkey в MQTT-брокер имеет все те же ключи, что и в Valkey, и преобразовывается в строковый тип данных через JSON.stringify().

Структура значения топика, передаваемого в MQTT из сервиса valkey-to-mqtt-transceiver:
```
'{
  "alias": string,
  "device_id": number | null,
  "dt": number,
  "modem_id": number | null,
  "value": number | null,
  "value_bool": boolean | null,
  "value_string": string | null
}'
```
Пример передаваемых значений в MQTT: 
```
'{
  "alias": "Run",
  "device_id": 1217,
  "dt": 1768294047491,
  "modem_id": 1375,
  "value": null,
  "value_bool": true,
  "value_string": null
}'
```

## Установка зависимостей

```bash
$ npm install
```

## Запуск проекта

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

$ npm run start:prod
```
